## 2026-10-11 — гибридный поиск и оценка качества

Коммит: [`3a2613e`](https://github.com/AITUSADC/aitunator/commit/3a2613e9cce66156bdabea503b41b63bdf81ca73)
— `feat: add hybrid retrieval pipeline`.
Первый коммит поисковой части после начального коммита репозитория.
Внесён напрямую в `main`, без отдельного PR.

### Реализовано

- Гибридный поиск BM25 + BGE-M3 с объединением результатов через RRF.
- Распознавание названий, алиасов и кодов 16 образовательных программ.
- Разбиение сравнительного вопроса на запросы по программам и сбалансированный
  отбор результатов в пределах общего top-5.
- Приоритет разделов о дисциплинах, навыках и карьере среди найденных кандидатов.
- Фильтрация по программе, типу документа и языку; диагностические времена поиска.
- Подготовка фрагментов и метаданных документов, адаптер эмбеддера и индексатор Qdrant.
- Экспериментальные структурированные карточки с сохранением исходного текста
  и происхождения данных.

### Оценка и принятые решения

- Добавлены набор из 139 вопросов, скрипты сравнения BM25/dense/hybrid,
  эксперименты с карточками, выбором разделов и confidence-routing.
- Добавлены 28 тестов поиска, метрик, карточек и отбора разделов.
- Сохранены методика экспериментов и результаты в `docs/`.
- В рабочей поисковой схеме оставлен гибридный поиск для каждого запроса.
  Ранний выход по confidence не включён из-за регрессий; обязательный
  нейросетевой reranker не включён из-за высокой задержки на CPU.
- Переэмбеддинг в формате карточек не выбран: после добавления приоритета
  разделов он не дал преимущества над исходными векторами.

Локальная проверка: 319 фрагментов, 139 вопросов, из них 92 с разметкой разделов.

| Метрика | Исходный гибрид | Разбиение по программам + приоритет разделов |
|---|---:|---:|
| Найдены все размеченные разделы в top-5 | 85/92 (92,4%) | 91/92 (98,9%) |
| Найдены разделы обеих программ в сравнениях | 3/8 | 8/8 |
| Найден нужный документ для общих вопросов | 30/30 | 30/30 |

Это метрики поиска, а не правильности ответов LLM. Для общих вопросов
размечены документы, а не полнота фактов. Сравнения программ включают шаблонные
вопросы; результат не заменяет независимую проверку. Замеры выполнены локально,
без сетевых задержек Qdrant и генерации.

### Организация проекта

- Код поисковой части оформлен в `backend/app/rag`, `providers` и `ingest`;
  оценка качества — в `eval`, проверки — в `tests`.
- Перенесены полезные компоненты незавершённого прототипа. Старый чат не включён
  в этот коммит; каталоги нового API и фронтенда оставлены как заготовки.
- Переписан README, добавлены зависимости и правила исключения локальных данных,
  моделей, кешей и секретов из Git.
