# RAG

`pipeline.py` — поиск и публичные async-функции `answer`, `startup`, `shutdown`.
`answering.py` — история, проверка достаточности фактов, повтор поиска и генерация.
`guardrails.py` — детерминированные проверки входного вопроса.
`runtime.py` — загрузка локального корпуса и embedder, состояние готовности.
`corpus.py` — общий для runtime и eval локальный BM25/векторный индекс.
`planner.py` — разбиение по явно названным программам.
`retriever.py` — BM25/dense/RRF и ранжирование кандидатов.
`structured.py` — карточки, выбор разделов и сборка служебного контекста.

`cli.py` — ручной запуск одного вопроса без API. Настройки и ограничения описаны
в корневом README. Качество генерации и производительность реальной LLM пока
не измерены. Qdrant пока используется индексатором, runtime работает локально.
