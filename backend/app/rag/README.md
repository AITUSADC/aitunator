# RAG

`pipeline.py` — готовая поисковая цепочка без генерации ответа.
`planner.py` — разбиение по явно названным программам; LLM-планировщика с историей пока нет.
`retriever.py` — BM25/dense/RRF и ранжирование кандидатов.
`structured.py` — карточки, выбор разделов и сборка служебного контекста.

Guardrails, оценка достаточности контекста, повтор поиска и генерация ответа
ещё не реализованы. Они будут добавлены сюда по ТЗ.
