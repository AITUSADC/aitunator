# API и хранение (Второй участник)

Реализовано в соответствии с `docs/contract.md` и ТЗ:

- `app.py` — приложение FastAPI:
  - `POST /api/chat` — потоковый ответ (SSE: `status`, `token`, `done`, `error`), лимит 1000 символов, таймауты 15 с (TTFT) и 60 с (общий), отмена задачи через `asyncio.CancelledError` при отключении клиента, атомарная запись в SQLite перед отправкой `done`.
  - `GET /api/sessions/{id}` — восстановление истории сообщений сессии.
  - `POST /api/feedback` — оценка ответа (`1` / `-1` или `up` / `down`) и комментарий с проверкой на ПДн.
  - `GET /api/programs` — список образовательных программ AITU.
  - `GET /api/health` — статус SQLite (WAL), доступность Qdrant и версия базы.
- `db.py` — работа с SQLite через `aiosqlite` в режиме `WAL`, таблицы `sessions`, `messages`, `feedback`, автоочистка сессий без активности более 30 дней при старте.
- `pii.py` — проверка вопроса, ответа ассистента и комментария оценки на персональные данные (ИИН, телефоны, email, номера карт и документов).
- `security.py` — rate limit (10 запросов/мин на IP), учёт `X-Forwarded-For` только от `TRUSTED_PROXY_IPS`, блокировка параллельных запросов внутри одной сессии (`session_busy`).
- `rag_bridge.py` — единая точка подключения `answer(question, history, program_code)` с автоматическим или явным (`RAG_MODE=mock|real`) переключением между моком и реальным RAG первого участника.
